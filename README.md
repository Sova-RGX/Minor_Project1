# GroupDNA 🧬

A Python + NumPy project that analyzes WhatsApp chat data and generates insights about group activity and members.

## Features

- Message analysis
- Messages per person
- Busiest day and hour
- Activity heatmap using NumPy
- Top words
- Response patterns
- Silent streaks
- Rule-based personality archetypes
- Final group report

## Tech Used

- Python
- NumPy
- File Handling
- Lists, Dictionaries, Sets & Tuples
- Functions, Loops & Conditionals

## Dataset

A sample WhatsApp-style chat dataset covering 60 days and 3,174 messages from 6 participants.

## Run

Open `GroupDNA.ipynb` in Google Colab or Jupyter Notebook and run the cells in order.
